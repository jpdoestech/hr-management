# UI Design Direction

The visual language uses deep navy, warm gold, and cool neutral surfaces to match the existing SCPA design direction.

## Data Display

Tables use:
- clear column hierarchy
- sticky headers
- larger row spacing
- quieter borders
- compact action buttons
- record counts
- page-size controls
- numbered pagination

## HR Operations

The operations workspace is intentionally employee-centric:

1. Employee Directory
2. Priority Work
3. Selected Employee Summary
4. Complete Employee Actions
5. Work History
6. Workflow Guide

This reduces the need for HR staff to navigate across separate modules for routine employee work.
