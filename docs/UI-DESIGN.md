# UI Design Direction

The palette, fonts, shared component tokens and responsive rules follow
`design-system/MASTER.md`. The workspace uses violet and charcoal; sign-in
retains its navy and gold identity.

## Data Display

Tables use:
- clear column hierarchy
- sticky headers
- compact rows with readable 13px record values
- quieter borders
- compact action buttons
- record counts
- page-size controls
- numbered pagination

## HR Operations

The operations workspace is intentionally employee-centric:

1. Employee Directory
2. Priority Work
3. Selected Employee Summary
4. Complete Employee Actions
5. Work History
6. Workflow Guide

This reduces the need for HR staff to navigate across separate modules for routine employee work.
